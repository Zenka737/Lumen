# Lumen — фоторедактор в браузере

Lumen — фоторедактор в духе Photoshop/Figma, написанный на Vite + TypeScript (strict) без UI-фреймворков. Рисование идёт через Canvas 2D, тяжёлые фильтры считаются в Web Worker. Интерфейс на русском.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # проверка типов + production-сборка в dist/
npm run preview      # раздать dist/
npm test             # unit-тесты (vitest)
npm run typecheck    # tsc --noEmit
```

Сквозной тест в реальном браузере (headless Chromium через playwright-core):

```bash
npx playwright-core install chromium-headless-shell   # один раз
npm run dev            # в отдельном терминале
npm run e2e            # скриншоты и экспортированные файлы попадут в e2e-out/
```

## Возможности

**Слои**: растровые, слои-изображения, редактируемые текстовые слои, слои-фигуры и корректирующие слои. Можно добавить, удалить, дублировать, перетащить для смены порядка, переименовать (двойной щелчок), скрыть, заблокировать, задать непрозрачность и режим наложения (обычный, умножение, экран, перекрытие, затемнение, замена светлым, мягкий свет, жёсткий свет, осветление и затемнение основы, разница, исключение, цветовой тон, насыщенность, цвет, яркость). Есть объединение с нижним слоем, сведение и «Растрировать слой».

**Фигуры**: прямоугольник, эллипс, линия, многоугольник (3–60 сторон) и звезда (число лучей и глубина). Скругление углов — общее или отдельно для каждого угла (↖ ↗ ↘ ↙) и четырёх стилей: круглое, плавное (squircle), срез и вогнутое. Всё хранится как данные слоя и правится в «Свойствах» до растрирования.

**Стили слоя** (панель «Свойства»): тень, внешнее свечение, обводка (снаружи, внутри, по центру), наложение цвета или градиента. Не меняют пиксели слоя и сохраняются в `.lumen`.

**Анимация** (панель «Анимация»): ключевые кадры положения, масштаба, поворота и непрозрачности слоёв с кривыми (линейно, разгон, торможение, плавно, ступенька), предпросмотр с проигрыванием, экспорт в GIF и WebM.

**Оформление** (кнопка с палитрой в верхней панели): акцентный цвет, скругление, плотность интерфейса и «жидкое стекло» — полупрозрачные размытые панели; в десктопном приложении на macOS окно просвечивает насквозь (vibrancy).

**Фильтры и коррекции** помимо базовых: двухцветное тонирование, постеризация, порог (три корректирующих слоя без потери качества), мозаика, размытие в движении, рельеф, контуры (Собель), хроматическая аберрация, чёткость (локальный контраст).

**Маски слоёв**: добавить («показать всё», «скрыть всё», из выделения), удалить, применить, инвертировать, выключить (Shift+щелчок по миниатюре), загрузить как выделение (⌘/Ctrl+щелчок). Щелчок по миниатюре маски переключает рисование на маску (⌘/Ctrl+\\): белый показывает, чёрный скрывает; работают кисть, ластик, градиент, заливка и очистка с учётом выделения. Маски хранятся в `.lumen` и в автосохранении.

**Корректирующие слои** (Слои → «Корр. слой», кнопка ◐ на панели «Слои»): яркость/контраст, цветовой тон/насыщенность, уровни, кривые. Действуют на всё, что ниже, не меняя пикселей; их можно скрывать, менять параметры в «Свойствах» (с отменой), переставлять и ограничивать маской. При объединении с нижним слоем коррекция «запекается».

**Текст и фигуры остаются редактируемыми**: двойной щелчок по тексту (или щелчок инструментом «Текст») открывает его для правки; шрифт, размер, цвет, жирный/курсив и выравнивание меняются в «Свойствах». У слоя-фигуры редактируются размер, заливка, обводка, толщина и скругление — до растрирования. Рисование кистью по такому слою растрирует его автоматически.

**Свободное трансформирование** (⌘/Ctrl+T, в браузере также ⌥⌘/Ctrl+Alt+T): слой или выделенные пиксели. Перетаскивание внутри — сдвиг (с привязкой), ручки — масштаб (Shift — пропорции, Alt — от центра), снаружи — поворот (Shift — шаг 15°), кнопки отражения и поворота на 90°, точные Ш/В/угол. Enter — применить, Esc — отменить; одна запись в истории. Маска трансформируется вместе со слоем.

**Линейки и направляющие**: линейки в пикселях (⌘/Ctrl+R) с маркером курсора. Направляющие вытягиваются из линеек, двигаются инструментом «Перемещение», удаляются перетаскиванием обратно на линейку. Привязка (⇧⌘;) к направляющим, краям и центру документа работает для выделения, рамки, фигур, градиента, перемещения и трансформирования.

**Инструменты**:

| Клавиша | Инструмент | Что умеет |
|---|---|---|
| V | Перемещение | Автовыбор слоя, сдвиг стрелками |
| M | Выделение | Прямоугольник или овал; Shift — добавить, Alt — вычесть или от центра |
| L | Лассо | — |
| W | Волшебная палочка | Допуск, смежные пиксели, «Все слои», добавить/вычесть |
| C | Рамка | Ручки, пропорции, Enter/Esc |
| I | Пипетка | Усреднение 3×3…11×11 |
| B | Кисть | Размер, жёсткость, непрозрачность, поток, сглаживание; нажим пера через Pointer Events |
| E | Ластик | — |
| S | Штамп | Alt+щелчок — источник, выравнивание, образец со всех слоёв |
| J | Точечное восстановление | Закрашенная область восстанавливается по окружению |
| G | Заливка / Градиент | Повторное G переключает; градиент линейный/радиальный, в прозрачность, на маске — плавный переход |
| T | Текст | Редактируемые текстовые слои |

| Z | Масштаб | Щелчок или протяжка |
| H / Space | Рука | — |

**Коррекция**: яркость/контраст, кривые (RGB и по каналам, редактор с гистограммой, ⌘/Ctrl+M), цветовой тон/насыщенность, экспозиция/гамма, насыщенность/красочность, цветовой тон, температура/оттенок, уровни (⌘/Ctrl+L), чёрно-белое, сепия, инверсия.

**Выделение**: прямоугольник, овал, лассо, волшебная палочка; выделить всё, снять, инвертировать, растушёвка (⇧F6), расширить, сжать. Растушёванное выделение — мягкая маска, её учитывают кисть, заливка, фильтры, трансформирование и маска из выделения.

**Фильтры**: размытие по Гауссу, резкость (нерезкая маска), виньетка, шум.

У всех коррекций и фильтров есть живой предпросмотр на уменьшенной копии. Он считается в Web Worker, ползунки устаревают корректно. После этого применяется полное разрешение с учётом выделения.

**История**: отмена и повтор (⌘/Ctrl+Z, ⇧⌘Z, ⌘Y) и панель истории с переходом к любому шагу. Для пиксельных правок хранится только изменённый прямоугольник. Объём ограничен: не больше 100 шагов и около 640 МБ, старые шаги вытесняются.

**Холст**: зум колесом с ⌘/Ctrl/Alt, щипком на трекпаде или жестом двумя пальцами на тач-экране. Панорама — пробел с перетаскиванием, средняя кнопка мыши или прокрутка. Есть «подогнать под экран» и 100%, шахматка под прозрачностью и пиксельная сетка при увеличении от 1000%.

**Файлы**:
- открыть через меню, перетащить файл или вставить из буфера обмена;
- новый документ с шаблонами;
- экспорт в PNG, JPEG или WebP с качеством и масштабом;
- проект `.lumen` (JSON со слоями в PNG; версия 2 хранит маски, направляющие, данные текста, фигур и корректирующих слоёв; файлы версии 1 открываются);
- автосохранение в IndexedDB и предложение восстановить работу при запуске.

**Изображение**: размер изображения, размер холста, поворот на 90° и 180°, отражение (всего изображения или одного слоя), кадрирование по выделению.

**Интерфейс**:
- тёмная и светлая тема, все цвета заданы токенами в CSS-переменных;
- панели можно сворачивать и менять их ширину, состояние запоминается;
- на ширине планшета (до 960 px) панели превращаются в выезжающую шторку;
- подсказки с горячими клавишами, шпаргалка по клавише `?`;
- HSV-пипетка цвета с HEX/RGB, палитрой и недавними цветами;
- видимые фокусы, клавиатурная навигация по меню и слоям.

**Стабильность**:
- проверка огромных изображений: предупреждение и уменьшение до 8192 px; жёсткий предел 16384 px по стороне и 120 Мп;
- ошибки показываются ненавязчивыми тостами;
- цикл отрисовки на requestAnimationFrame с флагами «грязно» и частичной перекомпоновкой по изменённому прямоугольнику;
- временные canvas и ImageBitmap освобождаются;
- предупреждение при закрытии вкладки, если автосохранение ещё не успело записать изменения.

    filters.ts    чистые фильтры (Node/Worker)
    worker.ts     Web Worker
    runner.ts     очередь, фолбэк на главный поток
  tools/          по файлу на инструмент, общий интерфейс Tool
  ui/
    app.ts        каркас
    canvasView.ts ввод, двойной щелчок по тексту/фигуре
    rulers.ts     линейки и перетаскивание направляющих
    curveEditor.ts редактор кривых
    commands.ts   команды, меню, горячие клавиши

## Ограничения

- Поворот/масштаб текста или фигуры (кроме простого масштаба фигуры без поворота и сдвига), поворот и размер всего изображения растрируют такие слои.
- Корректирующие слои — только поточечные (яркость/контраст, тон/насыщенность, уровни, кривые) и считаются в основном потоке при компоновке; на очень больших документах правка ползунков медленнее, чем у разрушающей коррекции (та считается в Web Worker).
- Направляющие не попадают в историю отмены.
- «Точечное восстановление» сглаживает область по окружению (без переноса текстуры), поэтому на сильно фактурных участках может выглядеть мягким.
- Инструмента «Палец» (smudge) нет.
- В браузере ⌘/Ctrl+T может перехватываться самим браузером (новая вкладка) — используйте ⌥⌘T / Ctrl+Alt+T или меню «Правка».
- Буфер обмена: системный используется, если браузер разрешает; иначе работает внутренний.
