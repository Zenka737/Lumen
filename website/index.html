Установка

macOS

  1. Откройте .dmg и перетащите Lumen в «Программы».
  2. Сборка пока без подписи Apple. При первом запуске: щёлкните Lumen правой кнопкой → Открыть → Открыть. Или в Терминале:
xattr -dr com.apple.quarantine /Applications/Lumen.app

Universal работает на любом Mac; Apple Silicon и Intel — версии поменьше.

Windows 10 / 11

  1. Установщик (.exe) ставит Lumen для текущего пользователя, создаёт ярлыки и связывает файлы.
  2. Portable — один .exe без установки, можно запускать с флешки.
  3. Сборка без подписи, поэтому SmartScreen может показать «Windows защитила ваш компьютер»: нажмите Подробнее → Выполнить в любом случае.

Linux

Ubuntu, Debian, Mint, Fedora, openSUSE, Arch и др.; GNOME, KDE, XFCE и любые другие окружения.

AppImage

chmod +x Lumen-*.AppImage
./Lumen-*.AppImage

Ubuntu / Debian (.deb)

sudo apt install ./Lumen-*-linux-amd64.deb

Fedora / RHEL / openSUSE (.rpm)

sudo dnf install ./Lumen-*-linux-x86_64.rpm

tar.gz

tar xzf Lumen-*-linux-x64.tar.gz
./Lumen-*/lumen

Если AppImage не стартует на Ubuntu 22.04+, установите libfuse2 (sudo apt install libfuse2t64) или запустите с --appimage-extract-and-run.

Проверка файла: shasum -a 256 файл (macOS), sha256sum файл (Linux), Get-FileHash файл (Windows) — сравните с SHA-256 выше.
